
# Wireshark Network Traffic Analysis Project

## 📌 Project Overview
This project focuses on analyzing real website network traffic using Wireshark. The goal is to understand how data packets are transmitted between a client and a web server and how different network protocols operate during communication.

The analysis includes studying packet flow, connection establishment, and encrypted communication when accessing websites.

---

## 🎯 Objective
To capture and analyze network traffic using Wireshark and understand how data packets travel between a client and a web server, focusing on protocols such as DNS, TCP, HTTP/HTTPS, and TLS.

---

## 🛠 Tools Used
- Wireshark
- Web Browser (for traffic generation)
- Operating System: Windows

---

## 📊 Key Protocols Analyzed
- DNS (Domain Name System)
- TCP (Transmission Control Protocol)
- HTTP/HTTPS
- TLS (Transport Layer Security)

---

## 🔍 Key Learnings
- How DNS resolves domain names into IP addresses
- TCP 3-way handshake process
- HTTP vs HTTPS communication differences
- How TLS encrypts data for secure communication
- Packet flow between client and server in real time


---

## 🚀 Conclusion
This project helped in understanding real-world network communication and packet-level data flow. It strengthened practical knowledge of networking protocols and how secure communication is established over the internet.
